# Application Screenshots / 应用截图

本目录保存 MotionCraft 应用在真机上的运行截图：

| 文件名 | 功能模块 | 界面说明 |
| --- | --- | --- |
| `logo.png` | 应用图标 (App Logo) | 高清 256x256 渐变应用 Logo 图标 |
| `logo.svg` | 矢量图标 (SVG Logo) | 矢量画质 MotionCraft 各种场景展示图标 |
| `01_gallery.png` | 实况图集 (Gallery) | 展示已导入的 Live Photos 网格、LIVE 动图角标与导入按钮 |
| `02_convert.png` | 视频剪辑与转实况 (Convert) | 提供实时视频帧时间轴截取、时长区间选择与标题设置 |
| `03_pairing.png` | 双选配对合成 (Pairing) | 支持静态图片+视频手动匹配配对，或多图合成实况 |
| `04_settings.png` | 系统设置 (Settings) | 提供深色模式、Material You 动态调色盘、多语言与缓存清理 |
